# NDI Job Configurator 0.8.11

Bundles the independently released PC Agent 0.7.3 (0.7.3-dev.1 for Development), fixing a Windows Firewall interface-list marshalling error that stopped installation and onboarding. This patch supersedes 0.8.10 after the error was reproduced during local deployment.

Includes the improved server-PC onboarding action, persistent failure/retry feedback and internal seven-day failure-report retention introduced in 0.8.10. Agent installation failures now retain the underlying exception and stack information in internal reports. Diagnostic logs remain out of the UI.

The new companion regression exercises the actual Windows COM rule object without adding a live firewall rule. The old implementation fails that check; the corrected UDP and TCP policies pass. Existing job membership, NDI settings and remote confirmation/UAC behavior are retained.
