# NDI Job Configurator 0.8.10

Server-PC onboarding now shows the selected job and settings, uses a styled action button, prevents duplicate submissions, and keeps failure/retry feedback visible. Successful onboarding remains successful when a subsequent display refresh fails.

Failed onboarding produces internal diagnostic reports with stage timelines and exception details. Reports are redacted, bounded, retained for seven days and available only through localhost retrieval on the server. Remote reports are scoped to an existing onboarding attempt and cannot change job membership or configuration permission. Logs are not displayed in the UI.

The optional, default-selected PC Agent component is the independently released 0.7.2 package (0.7.2-dev.1 for Development). Its durable diagnostic queue retries after network or server outages. Existing remote confirmation and UAC behavior are retained.

Validation: 23 server regression checks, 12 frontend tests, installer validation, both PC Agent validation projects, 12 cross-repository scenarios and real isolated HTTP diagnostic checks passed. Builds completed without warnings or errors. The original reported live onboarding fault still needs reproduction with this updated pair to capture its cause.
