# NDI Job Configurator 0.8.9

This release hardens interoperability with PC Agent, Environment Setup, Production Toolkit and Resolume Configurator. Durable onboarding outcomes survive transient failures, stale or denied requests cannot authorize later writes, and stable job identities prevent same-name replacements from being confused. Installer recovery, package validation and download readiness preserve client-only and combined-server deployments.

The optional PC Agent remains selected by default and independently deployed. Main bundles PC Agent 0.7.1; Development bundles 0.7.1-dev.1, each from its clean matching released source.

Validation: 22 server regression checks, 8 frontend checks, installer package/retention checks, 11 onboarding interoperability scenarios, and the isolated server-to-Resolume HTTP contract passed before release preparation.
