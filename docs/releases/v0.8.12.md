# NDI Job Configurator 0.8.12

Windows endpoint cards now start collapsed, showing the PC name, IP address, connectivity and any attention warning in a compact summary. Click the summary or use the keyboard to reveal health details and onboarding, reapply and removal controls.

Each card expands independently and stays open during background refreshes and registration updates. Newly discovered cards and page reloads start collapsed. The layout was verified on desktop and mobile, including keyboard operation and background polling.

All 23 server regression checks, 13 frontend checks and the installer suite passed. This release bundles the existing independently published PC Agent 0.7.3 (0.7.3-dev.1 for Development).
