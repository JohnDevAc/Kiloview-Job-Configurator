# NDI Job Configurator 0.8.16

N6 onboarding and encoder renaming now keep separate channel names for the two codec profiles: HX uses the entered name, and Full NDI appends `-HB`. Previously both profiles received the same name, contrary to the N6 API requirements.

Both profiles are checked before naming. Updates avoid intermediate name collisions, skip unchanged rename settings, and verify the saved identity and codec readiness after each write. Profile errors are reported instead of silently ignored. Selecting an onboarded N6 as an encoder also repairs legacy names; decoder naming leaves inactive encoder profiles alone.

N6 source selection and encoder thumbnails prefer an exact channel name over a suffixed sibling. N60 naming is unchanged. These releases bundle the existing, separately published PC Agent 0.7.5 (Main) or 0.7.5-dev.1 (Development).

Validation: 36 backend regression checks, 18 frontend tests, frontend syntax and installer helper checks passed with isolated configuration. Live repair on four N6 encoders changed only each Full NDI channel name and preserved HX video and codec readiness. The causal relationship between duplicate names and the previously reported codec-service crashes remains unproven.
